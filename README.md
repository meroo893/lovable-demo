# Промпт инженеринг за учители – 10 съвета

Едностраничен сайт с 10 практични съвета как учителите да пишат по-добри промптове към AI (планове на уроци, тестове, обратна връзка). Дизайн в училищна тематика – дъска и тетрадка.

**Стек (съвместим с Lovable):** Vite · React 18 · TypeScript · Tailwind CSS · lucide-react

## Функции
- 10 съвета с примери „преди/след“ и обяснение „Защо работи?“
- Бутон за копиране на добрия промпт
- Филтър по категория (Основи, Техника, Структура, Стратегия)
- Отметки „Научих урока“ с лента за напредък (пазят се в браузъра)
- Избор от 3 цветови палитри (розова, класическа, слънчева), която се пази в браузъра; палитрите се редактират в `src/index.css` и `src/data/palettes.ts`
- Светла/тъмна тема, адаптивен дизайн за мобилни устройства

## Локално стартиране
```bash
npm install
npm run dev     # http://localhost:8080
npm run build
```

## Импорт в Lovable
1. В Lovable: **Settings → GitHub → Connect** и изберете това хранилище.
2. Lovable ще разпознае Vite проекта автоматично.
3. Натиснете **Publish**, за да получите публичен адрес.

Съветите се редактират в `src/data/tips.ts`.
